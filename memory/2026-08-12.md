### The "existing math" rate formula (IMPORTANT - reuse for any rate work)
Single Ad by Case Count (cc):
- cc<=7 -> $2,400 (flat)
- 8-14  -> 2400 + (cc-8)*150
- 15-22 -> 3300 + (cc-14)*125
- 23-30 -> 4300 + (cc-22)*100
- 31-55 -> 5100 + (cc-30)*75
- cc>=55 -> $6,975 (cap)
Double Ad = Single * 1.4 (flat = Single at cc<=7).
Mins: SingleMin = Single*0.9, DoubleMin = Double*0.9.
Premium chains carry a multiplier on top (embedded in the card): 1.15x = Lowes, Winn Dixie, Harveys; 1.30x = Fred Meyer, Carrs, Calgary/North Central/Red River/South Country/Leduc Co-op, some Safeway. Their Double uses their own ratio (Lowes/WinDixie ~1.25 single->double).

## CYCLE -> START MONTH mapping (Tyler, Aug 12) — ad rotation calendar
Store `Cycle` letter (A/B/C) + quarter number = which month the cycle starts. Rotates every 3 months.
- A1=January, B1=February, C1=March
- A2=April,   B2=May,      C2=June
- A3=July,    B3=August,   C3=September
- A4=October, B4=November, C4=December
Pattern: A=1st month of quarter, B=2nd, C=3rd. Start month = (quarter-1)*3 + cycleIndex(A=1,B=2,C=3).
So by cycle letter, the start months are:
- A: Jan, Apr, Jul, Oct
- B: Feb, May, Aug, Nov
- C: Mar, Jun, Sep, Dec
Use to inform the audit tool (AuditStore.svelte) and any scheduling. Built shared helper `pwa/src/lib/cycleSchedule.js`.
